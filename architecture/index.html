Апп бүр Nexus-ийн нэг гэрээг дагана

Каталогийн апп бүр Nexus-д компиллогдсон модуль эсвэл гадаад OIDC апп байна. Аль байгууллагад аль нь идэвхтэйг тухайн байгууллагын суулгалт шийднэ.

nexus
01

Компиллогдсон Go модулиуд

Модуль бүр pkg/nexus Go гэрээг хэрэгжүүлж нэг API бинарид компиллогдоно. Маршрут, цэс, эрх, миграцаа module өөрөө бүртгэнэ.

02

Тенант бүрийн апп стор

Аль байгууллагад аль апп идэвхтэйг өгөгдлийн сан шийднэ. Суулгаагүй апп руу хандвал хориглоно — код нь байгаа ч хаалга нь хаалттай.

03

Хамаарал шийдвэрлэгч

Рекурсив шийдвэрлэлт, мөчлөг илрүүлэлт, хувилбарын шалгалт. Апп суулгахад түүний хамаарал бүр тохирох хувилбартайгаа хамт орно.

04

Гарын үсэгтэй remote каталог

Nexus суулгац APP_CATALOG_URL-аар энэ дэлгүүрийн каталогийг татаж, APPSTORE_PUBLIC_KEY-ээр гарын үсгийг шалгана. Шалгалт унавал cache эсвэл bundled каталог руу аюулгүй буцна.
